# 转换工作流

把高中物理试卷 PDF 转为符合 MathLive 规范的 LaTeX 源码，并为每题自写解析。格式细则见 [mathlive-format.md](mathlive-format.md)。

## 依赖

Python 环境需安装 `pymupdf`（PyMuPDF）、`Pillow`。脚本位于本 skill 的 `scripts/` 目录。

## 产物目录约定

每次转换一个 PDF，在工作目录下建立：

```
<工作目录>/
├── <卷名>.tex            # 成稿 LaTeX 源码
├── images/               # 裁切出的题目图形 PNG
├── preview/              # 探查阶段生成的逐页预览图与文字层（非交付物）
└── 转换说明.md            # 答案汇总、争议题标注、图片清单（可选交付）
```

## 阶段 1：探查 PDF

运行 `scripts/probe_pdf.py`：

```bash
python scripts/probe_pdf.py "<试卷.pdf>" --out preview
```

- 脚本打印页数、每页文字量/图片数/矢量绘图数，以及图片和绘图的 bbox；同时把每页渲染成 1.6x PNG、导出文字层 txt 到 `preview/`。
- **先逐页看预览 PNG**，判断文字层质量：公式、上下标、电路图、光路图、坐标图分别落在哪。文字层只用于定位，不作转写依据。
- 记录每张无法转写为 LaTeX 的图形（装置图、电路图、磁场/电场示意图、选项配图）所在页码与 bbox，供阶段 2 裁切。

## 阶段 2：裁切图形

编写裁切清单 JSON（参照 `scripts/crop_images.py` 头部格式）：

```json
{
  "pdf": "<试卷.pdf>",
  "outdir": "images",
  "zoom": 3.0,
  "crops": [
    {"page": 2, "name": "q05_pulley", "rect": [54, 83.3, 214.6, 163.6], "margin": 6}
  ]
}
```

- 命名规则 `q<两位题号>_<内容缩写>.png`；选择题的四个选项配图用 `q06_A/B/C/D.png`。
- bbox 以探查输出为初值，对照预览图微调，`margin` 留少量白边防止切到标注文字。
- 运行：`python scripts/crop_images.py <清单.json>`，3 倍分辨率输出。
- 裁切后逐张打开确认：图形完整、标注清晰、没有混入相邻题目。

## 阶段 3：转写题干、选项与公式

对照预览 PNG 逐题转写，不依赖文字层：

1. 题干：叙述文字、已知量、设问。物理量与单位按 mathlive-format.md 写入数学模式。
2. 选项：每题 A–D 分行书写；选项为配图的，引用对应裁切 PNG。
3. 表格：用 `array` 环境。
4. 跨页题目：合并到同一题编号下。

答案核对：检索公开真题/权威解析交叉核对选择题答案与计算题结果；回忆版、网传版本若答案存在分歧，以物理规律判断为准，并在 `转换说明.md` 标注争议点。

## 阶段 4：撰写解析

解析必须用自己的语言重写，不能只抄参考答案：

- **选择题**：逐项判断对错，每项给出物理依据（定律、公式、趋势分析），不只写"正确/错误"。
- **实验题**：说明操作目的、读数/挡位选择理由、误差来源。
- **计算题**：列关键受力/过程分析 → 主干方程 → 代入数值 → 结果与单位；中间步骤保留，便于复习追溯。
- 答案行单独一行：`\textbf{答案：...}`，置于该题解析之后。

## 阶段 5：成稿与校验

- tex 骨架：卷标题用 `\section*{...}`；每题以 `\noindent <题号>. ` 开头；题图紧跟题干，按规范写绝对路径。
- 题间留三个源码空行；填空用裸下划线；不使用 `\quad`/`\qquad`/`\vspace`。
- 运行校验：

```bash
python scripts/verify_tex.py "<卷名>.tex"
```

校验通过条件：图片引用全部命中、题号齐全、无违禁命令、无间距/转义残留。若报 FAIL，按输出逐项修正后重跑。

## 交付物

- `.tex` 源码 + `images/` 图形目录（必须一起交付，图片为本地绝对路径引用）。
- 可选 `转换说明.md`：答案速查表、争议题说明、图片清单。
