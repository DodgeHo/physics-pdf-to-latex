# 转换工作流（单卷详解）

把一份物理试卷 PDF 转为符合 MathLive 规范的 LaTeX 源码，并为每题自写解析。格式细则见 [mathlive-format.md](mathlive-format.md)，多卷批量与并行见 [batch-spec.md](batch-spec.md)。

## 依赖

Python 需装 `pymupdf`（PyMuPDF）与 `Pillow`。脚本都在本 skill 的 `scripts/` 目录。

## 产物目录

```
<root>/
├── tex输出/<卷名>/<卷名>.tex      # 成稿
├── tex输出/<卷名>/images/*.png    # 配图（成稿引用的绝对路径目标）
├── tex输出/<卷名>/preview/        # 逐页预览 page_N.png + page_N.txt（非交付物）
├── tex输出/_notes/<卷名>.md       # 问题记录（交付物）
└── _tmp/<卷名>/                   # 全量裁图 pNN_k.png、_figs.json、_sheet.png（非交付物）
```

## 阶段 1：探查 + 裁图 + 总览（一条命令）

```bash
python scripts/prep.py "<试卷.pdf>" "<卷名>" [--root <批次根目录>] [--scan]
```

- 等价于依次跑 `probe_pdf.py`（1.6x 预览 + 文字层）、`qfig.py --min-area 3000`（按页裁出所有图形区域）、`sheet.py --cols 5 --maxw 340`（编号总览）。
- `--scan`：纯扫描件额外输出 `_tmp/<卷名>/hi/hN.png`（3.6x 整页），用于辨认小字与刻度。
- 默认写成 `<root>/tex输出/<卷名>/...`，`<root>` 用 `--root` 指定，便于换批次。

## 阶段 2：判读裁图归属

**先读 `_sheet.png`，再读页图**，不要反过来。

- `qfig.py` 故意不做"题号归属"：它只保证不丢图，命名是 `pNN_k`（第 N 页第 k 块）。裁图属于哪题，靠对照页图人工判断。
- 批注框、水印、页脚小图标常被误检成图形，判读时直接丢弃；同一图被重复裁出时保留清晰那张。
- `_sheet.png` 标注的 `pNN_k` 与实际文件名偶尔差一位，之后 verify 报 missing 时就按 `_tmp/<卷名>` 的真实文件名改引用。
- 选项图像题（四个选项各是一张图）：全部引用，按页内位置顺序写，并在正文注明"四幅图像依次对应 A、B、C、D"；也可先用 `compose.py` 合成带标签的 `qNN_opts.png`。

## 阶段 3：转写题干、选项与公式

对照 `preview/page_N.png` 逐题转写，**文字层只用于定位**（公式上下标、分式、单位几乎总会错位）。

1. 题干：叙述、已知量、设问；物理量与单位按 mathlive-format.md 写入数学模式。
2. 选项：A–D 各占一行；选项为图像的引用裁图。
3. 表格：`array` 环境，不画横线。
4. 跨页题合并到同一题号下；源缺题按源题号跳号，不造占位题。

**答案来源层级**（顺序不可颠倒）：

1. 源 PDF 自带答案键（常见 `【答案】`、页内批注）；
2. 源与本卷详解：只用来核对，冲突时以答案键为准并登记；
3. 完全没有答案 → 自行推导，登记"需人工复核"；
4. 网络答案册/解析版：**只作比对，不作依据**，一律以独立推导落笔，差异写进问题记录。

## 阶段 4：撰写解析

解析必须自己重写，不能照抄参考答案；取要点式，不堆废话。

- 选择题：逐项判断，每项一句物理依据（定律、公式、趋势），不只写"对/错"。
- 实验题：操作目的、读数与挡位理由、误差来源；作图/连线题写清具体做法（如"撤出力传感器与重物，垫起木板左端使小车匀速下滑"）。
- 计算题：关键过程分析 → 主干方程 → 代入 → 结果与单位；中间步骤保留，但不重复题面。
- 每题末尾固定两行：`答案：…` 与 `解析：…`，不加粗、不加编号。
- 与答案键冲突时，解析末尾加 `（与答案键存在出入，已登记待核）`。

## 阶段 5：成稿与校验

- 骨架：`\section*{YYYY年物理试卷（XX卷）}` + `共 N 题 | 题型统计` + 每题 `\noindent N. (题型) (YYYY-省卷-N) 题干`；题间三个源码空行。
- 图片引用绝对路径 + 正斜杠，宽度惯例：单图 0.3–0.45，四张选项小图各 0.17，细长图 0.5。
- 把 `_tmp/<卷名>/p*.png` 拷入 `tex输出/<卷名>/images/`（先清空旧图，避免残留副本），再校验：

```bash
python scripts/verify_tex.py "<卷名>.tex"
```

通过条件：`refs=N missing=[] questions=[...]` 且 `OK`。报 FAIL 就按输出逐项修，别绕过。

## 阶段 6：写问题记录

`tex输出/_notes/<卷名>.md`，五栏固定：源文件名 / 题数·配图数 / 校验结果 / 问题逐条。没有答案键的扫描卷、回忆版残缺、图像选项映射不确定、与答案键冲突、缺题跳号，全部写进去；确认干净的写"无"。

## 交付物

- `<卷名>.tex` + `images/`（必须同时交付）。
- `_notes/<卷名>.md`（问题记录，必须交付）。
- 多卷批次另有根目录 `汇总说明.md`（索引 + 待核清单）。
