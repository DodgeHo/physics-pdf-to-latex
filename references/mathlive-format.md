# MathLive 格式硬规范

生成的 `.tex` 必须能在 MathLive 编辑器中直接渲染。以下约定为硬性要求，校验脚本 `scripts/verify_tex.py` 会自动检查其中可机检的部分。

## 禁用清单

| 禁用项 | 原因 | 替代写法 |
| --- | --- | --- |
| `\begin{tabular}...\end{tabular}` | MathLive 支持有限 | 用 `\begin{array}{...}` 环境 |
| `\hline` | array 内不支持 | 依赖列对齐表达，不画横线；必要时用 `\mid` 风格分隔 |
| `\begin{itemize}` / `\begin{enumerate}` | 列表环境不支持 | 选项与小问直接分行纯文本编号 |
| `\ce{...}` | 化学式宏包不可用 | 核素/元素用数学模式手写（见下） |
| `\begin{align}` | 对齐环境不可用 | 每个方程单独 `$...$` 分行书写 |
| `\quad` / `\qquad` | 间距命令按用户规范去除 | 普通空格分隔；数学式内逗号后留一个空格 |
| `\vspace{...\baselineskip}` | 不用 LaTeX 间距命令 | 源码层面直接留空行（见下） |
| `\_` 转义下划线 | 填空横线不需要转义 | 直接写裸下划线串 `__________` |

## 表格（array）

```latex
\begin{array}{|c|c|c|c|}
测量序号 & B_x/\mathrm{\mu T} & B_y/\mathrm{\mu T} & B_z/\mathrm{\mu T} \\
1 & 0 & 21 & -45 \\
2 & 0 & -20 & -46 \\
\end{array}
```

- 列格式用 `c|c` 这类竖线分隔；行之间用 `\\`。
- 不要写 `\hline`。

## 选项与小问

选项每行一条，纯文本编号，不套列表环境：

```latex
A. 弹簧上形成的波是横波

B. 推、拉弹簧的周期越小，波长越长

C. ...

D. ...
```

小问用 `（1）`、`（2）①` 这样的中文编号直接写在段落里。

## 核素写法

上下标同时存在时用 `${}_{左下}^{右上}\mathrm{元素}$`：

```latex
${}_{90}^{232}\mathrm{Th}$ 俘获 ${}_{0}^{1}\mathrm{n}$，转化为 ${}_{92}^{233}\mathrm{U}$
```

## 单位与符号

- 单位放进 `\mathrm{}`：`$10\mathrm{m/s^{2}}$`、`$6\Omega$`、`$1.0\mathrm{kg}$`。
- 下标带字母或多字符时必须加花括号：`$F_{1}$`、`$v_{0}$`、`$n_{1}:n_{2}$`；单字符下标可写 `$v$`。
- 希腊字母照常：`$\theta$`、`$\beta$`、`$\mu T$`。
- 分数用 `\dfrac{}{}`；根号用 `\sqrt{}`；角度用 `$0^{\circ}$`。

## 排版约定

- **题间空行**：题与题之间在源码中直接留三个连续空行（`\n\n\n`），不使用任何 `\vspace` / `\par` 间距命令；同题内段落之间留一个空行。
- **图片路径**：`\includegraphics` 使用本地绝对路径，正斜杠写法：
  ```latex
  \includegraphics[width=0.45\textwidth]{C:/Users/.../images/q02_spring.png}
  ```
- **填空横线**：直接写 `__________`，不转义。
- **选择题括号**：题干末尾写 `（ ）`，括号内一个普通空格。
- **答案行 / 解析行**：直接写 `答案：B`、`解析：`，不要用 `\textbf{}` 包裹；答案多小问写在一行，小问之间空格分隔。

## 易错点

- PDF 文字层的公式上下标经常错位/乱序，**必须对照渲染预览图逐题核对**，不能直接复制文字层。
- 下标花括号前不要出现反斜杠：`_{1}` 正确，`\_{1}` 错误。
- 裁好的图片先确认文件存在，再写进 `\includegraphics` 路径。
